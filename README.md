Этот проект представляет собой реализацию Pokemon API для работы с данными о покемонах. Основная функциональность включает поиск покемонов по классам и по имени. Реализует сортировку по имени и характеристикам и фильтрацию по классам.

Реализованные библиотеки:
Retrofit, Room, Koin, Coroutines, Flow, Git, SQL, Paging Compose.

Ключевые возможности:
- UI: Jetpack Compose;
- Поиск покемонов по заданным классам (типам, категориям и др.);
- Сортировка результатов по имени, урону и другим заданным параметрам;
- Фильтрация по нескольким характеристикам для точного отбора;
- MVVM архитектура проекта.
